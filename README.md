# Projeto-2---Calculadora
Para um projeto de calculadora em JavaScript, crie os arquivos HTML, CSS e JavaScript para estruturar, estilizar e adicionar a funcionalidade interativa, respectivamente. No JavaScript, você usará variáveis para armazenar os números e a operação, capturará os cliques dos botões com eventos de clique, e manipulará o DOM para exibir os números.
